---
title: "AI provider settings"
description: "Why Tenant Settings no longer has an AI section, and where Darpan's AI features are turned on."
---

Tenant Settings used to have an **AI** section that stored an AI provider, model and key. No Darpan feature read those settings, so the section is gone from the app after app 4.4.19. Nothing about how a run behaves changes.

<Note>
The AI features Darpan does have take a separate path. The audit agent, and the lines Claude writes in an audit's update after each run, are turned on per tenant by a Darpan admin, and the agent answers only users a Darpan admin has given AI access with a spend limit. Neither read the old settings. See [The audit agent](/guides/audits#the-audit-agent) and [AI access](/guides/manage-users-and-access#ai-access).
</Note>
