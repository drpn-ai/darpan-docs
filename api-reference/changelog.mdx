The generated contract carries `info.x-darpan-contract-version`, decoupled from the product release version. The policy is additive-only: new methods, new optional parameters, and new response fields ship without a bump; breaking changes require a conscious one. See [Contract versioning](/api-reference/json-rpc#contract-versioning).

| Contract version | Darpan releases | Public `facade.*` methods |
| --- | --- | --- |
| 3 (current) | 1.5.0, 1.5.1 | 86 |
| 2 | 1.2.0, 1.3.0, 1.4.0 | 73 |
| 1 | 1.0.0 to 1.1.0 | 66 |

Releases 1.3.0, 1.4.0, and 1.5.1 added or removed no methods.

<Note>
Operator-only methods (`admin.*`) are listed in the [service catalog](/api-reference/service-catalog#administration) but are not part of the public API. They serve the operator admin application and require a super-admin caller, so integrations should not depend on them. The counts below mention them only so the totals add up.
</Note>

## Contract version 3

Darpan 1.5.0. Current.

### Breaking change

- `facade.SettingsFacadeServices.list#TenantChatSpaces` no longer returns `chatSpaces[].googleChatWebhookUrlMasked`. Webhook URLs are now stored in clear text and returned in `webhookUrl` (and in `googleChatWebhookUrl`, the pre-Slack name).

### Added

Expired-password recovery:

- `facade.AuthFacadeServices.change#ExpiredPassword`

Anonymous by necessity, because the account cannot hold a session until the password changes. It requires the account's current password.

Slack notifications:

- `facade.SlackFacadeServices.begin#SlackInstall`
- `facade.SlackFacadeServices.save#SlackBotToken`
- `facade.SlackFacadeServices.get#SlackInstall`
- `facade.SlackFacadeServices.list#SlackChannels`
- `facade.SlackFacadeServices.disconnect#SlackWorkspace`

A chat space now names a chat product. Existing Google Chat spaces are unaffected.

Config sharing across tenants:

- `facade.ConfigSharingFacadeServices.grant#ConfigTenantAccess`
- `facade.ConfigSharingFacadeServices.revoke#ConfigTenantAccess`
- `facade.ConfigSharingFacadeServices.list#ConfigTenantAccess`

Source endpoint access:

- `facade.SourceEndpointFacadeServices.list#SourceConfigEndpoints`
- `facade.SourceEndpointFacadeServices.store#SourceConfigEndpointAccess`

CSV schema inference:

- `facade.JsonSchemaFacadeServices.infer#JsonSchemaFromCsvText`

Automation sync:

- `facade.ReconciliationFacadeServices.sync#Automation`

Re-derives an automation's snapshot from its saved run. `get#Automation` gains a `syncStatus` map reporting snapshot drift; this is an additive response field.

That is 13 public methods. The release also added 7 operator-only `admin.*` methods.

## Contract version 2

Darpan 1.2.0. Unchanged through 1.3.0 and 1.4.0.

### Removed

Replaced by the chat-space registry:

- `facade.SettingsFacadeServices.get#TenantNotificationSettings`
- `facade.SettingsFacadeServices.save#TenantNotificationSettings`

Callers reading or writing the single tenant webhook should move to `list#TenantChatSpaces` and `save#TenantChatSpace`. Existing webhooks are carried over automatically on upgrade. See [Run-completion alerts](/guides/run-completion-alerts#upgrading-from-the-single-tenant-webhook).

### Added

Chat-space notifications:

- `facade.SettingsFacadeServices.list#TenantChatSpaces`
- `facade.SettingsFacadeServices.save#TenantChatSpace`
- `facade.SettingsFacadeServices.delete#TenantChatSpace`
- `facade.SettingsFacadeServices.get#UserNotificationDefault`
- `facade.SettingsFacadeServices.save#UserNotificationDefault`

Run control and notification:

- `facade.ReconciliationFacadeServices.cancel#ReconciliationRun`
- `facade.ReconciliationFacadeServices.subscribe#RunNotification`
- `facade.ReconciliationFacadeServices.unsubscribe#RunNotification`

Connections:

- `facade.SettingsFacadeServices.test#SourceConnection`

That is 9 public methods added and 2 removed. The release also added 17 operator-only `admin.*` methods.

## Contract version 1

Baseline contract, Darpan 1.0.0 (65 methods, all `facade.*`).

- JSON-RPC 2.0 transport over `POST /rpc/json`.
- Auth channels: HttpOnly `darpan_login_key` cookie plus CSRF token (browser, canonical) and `login_key` header (integration callers and fallback).

### Added in 1.1.0

- `facade.ReconciliationFacadeServices.get#ReconciliationRunStatus`
